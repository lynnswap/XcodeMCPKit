# Streamable HTTP migration — v0.11.0

If you use the proxy through Codex or Claude Code, no migration is required
for v0.11.0.

Direct Streamable HTTP clients must:

- After `initialize`, send the server-issued `MCP-Session-Id` and
  `MCP-Protocol-Version: 2025-06-18`.
- Include `Accept: application/json, text/event-stream` on `POST /mcp`.
- Send individual JSON-RPC messages instead of batch requests.

See the [HTTP contract](../architecture.md#streamable-http-contract) for current
session, header, and error handling, and the [migration index](README.md) for
later changes.
