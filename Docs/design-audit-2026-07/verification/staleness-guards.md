The generation component of the pre-write lease check (:533-540 via :708-722) is repeated by the funnel's :639 check for the store write itself, but remains load-bearing for intermediate non-funnel side effects. The funnel's own checks at :957 and :961 are separated by a synchronous hook, yet a production thread can still mutate broker state between the reads because ControlPlaneCoordinator.swift:255-260 calls brokerState.clearToolsCatalog outside the funnel lock. The second check can therefore catch a race; it is not dead.
